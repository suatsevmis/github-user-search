# GitHub Kullanıcı Arama Uygulaması

Bu proje, **GitHub Rest API** kullanarak kullanıcı profillerini ve açık kaynak depolarını (repositories) dinamik olarak listeleyen bir web uygulamasıdır.

## 🚀 Özellikler

- **Profil Bilgileri:** Kullanıcının profil fotoğrafı, adı, kullanıcı adı, biyografisi ve konumu.
- **İstatistikler:** Takipçi (followers), takip edilen (following) ve açık kaynak depo (repository) sayıları.
- **Depo Listesi:** Kullanıcının öne çıkan veya son repolarının bağlantılarıyla birlikte listelenmesi.

## 🛠️ Kullanılan Teknolojiler

- **HTML5:** Sayfa yapısı ve iskelet sistemi.
- **CSS3:** Arayüz tasarımı ve stillendirme.
- **JavaScript (ES6+):** DOM manipülasyonu ve asenkron veri işleme.
- **Axios:** GitHub API'ye HTTP istekleri göndermek için kullanılan kütüphane.
- **Font Awesome:** Arayüz ikonları.
